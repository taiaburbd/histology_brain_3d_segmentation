## Inference
Inference is performed using the best model across all trained folds:
```bash
!nnUNetv2_predict -d Dataset003_HPC -i INPUT_FOLDER -o OUTPUT_FOLDER -f  0 1 2 3 4 -tr nnUNetTrainer -c 3d_lowres -p nnUNetPlans
```

### Command Breakdown

- **`-d Dataset003_HPC`**: Specifies the dataset identifier, indicating which dataset or task is being processed.

- **`-i INPUT_FOLDER`**: Indicates the input folder where the images or data for prediction are located, which should be formatted according to nnU-Net specifications.

- **`-o OUTPUT_FOLDER`**: Designates the output folder where the prediction results, such as segmentation maps, will be stored.

- **`-f 0 1 2 3 4`**: Specifies the folds used for prediction. Using multiple folds (0 through 4) suggests an aggregation of results across these folds to enhance the robustness and generalizability of the predictions.

- **`-tr nnUNetTrainer`**: Specifies the trainer class, with `nnUNetTrainer` being a standard option in nnU-Net that comes with predefined settings for network architecture and data handling.

- **`-c 3d_lowres`**: Indicates that the model configuration used is '3d_lowres', suitable for scenarios requiring reduced computational resources or for handling large datasets at a manageable resolution.

- **`-p nnUNetPlans`**: Points to the planning file used which contains metadata about the model setup including network architecture details and data preprocessing strategies.
