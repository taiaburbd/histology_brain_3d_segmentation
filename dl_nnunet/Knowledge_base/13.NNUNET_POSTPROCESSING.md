## Post-processing
Following inference, post-processing is applied to enhance the results further:
```bash
!nnUNetv2_apply_postprocessing -i OUTPUT_FOLDER -o OUTPUT_FOLDER_PP -pp_pkl_file /path/to/postprocessing.pkl -np 8 -plans_json /path/to/plans.json
```

### Command Breakdown

- **`-i OUTPUT_FOLDER`**: Specifies the input directory containing the nnU-Net model's prediction results. Post-processing will be applied to the files in this folder.

- **`-o OUTPUT_FOLDER_PP`**: Designates the output directory where the post-processed results will be stored, keeping the original predictions separate from these modified results.

- **`-pp_pkl_file /path/to/postprocessing.pkl`**: Points to a pickle file containing the post-processing configuration used by nnU-Net. This file, generated during the model training phase, includes essential operations like threshold adjustments and connectivity analyses to refine predictions.

- **`-np 8`**: Indicates the number of processes to utilize during post-processing, leveraging parallel processing capabilities to speed up the operation. The value `8` suggests the use of eight cores.

- **`-plans_json /path/to/plans.json`**: Refers to the JSON file that contains detailed plans on how the nnU-Net was set up during the planning and preprocessing phases. It ensures that the post-processing steps align with initial data processing and segmentation strategies.
