
# Evaluation Metrics Documentation for `08.evaluation_matrix.ipynb`

This document describes the functionalities implemented in the `08.evaluation_matrix.ipynb` notebook, which is designed for evaluating medical image segmentation models using metrics like Dice coefficient, Hausdorff distance, and Relative Absolute Volume Difference (RAVD). Additionally, it includes procedures for saving these metrics to an Excel file and visualizing segmented regions in 3D.

## Overview

The `08.evaluation_matrix.ipynb` notebook provides tools to quantitatively assess the performance of segmentation models, offering insights into their accuracy and reliability in clinical settings.

## Key Functionalities

### Calculation of Evaluation Metrics

- **Dice Coefficient**: Measures the overlap between the predicted segmentation and the ground truth, providing a score between 0 and 1, where 1 indicates perfect overlap.
- **Hausdorff Distance**: Calculates the maximum distance of the set of closest points between the predicted and actual segmentations, offering insight into the largest error between the two.
- **Relative Absolute Volume Difference (RAVD)**: Computes the relative volume difference between the predicted and actual segmentations, indicating volume accuracy.

### Data Storage

- **Excel Output**: Metrics for each evaluated segmentation are compiled and saved into an Excel file, facilitating easy access and analysis.

### Visualization of Segmented Regions

- **3D Views**: Provides visualizations of segmented regions in 3D, allowing for a more intuitive understanding of the spatial relationships and segmentation accuracy.
