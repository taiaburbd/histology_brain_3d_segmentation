# Shell Script for nnUNet Prediction

This guide provides detailed steps to run a shell script for executing nnUNet predictions on a specific dataset.

## Prerequisites

- Access to a user account on the CCUB server.
- Basic understanding of shell scripting and command-line operations.
- Installed modules: PyTorch, Conda, nnUNet.

## Script Overview

This script performs the following actions:

1. Sources the user's bash configuration.
2. Loads the necessary PyTorch module.
3. Changes the working directory to the project root.
4. Activates a Conda environment.
5. Executes nnUNet prediction.
6. Logs Python and Conda versions to a file.

## Script Details

### Script

```bash
#!/bin/bash

# Source the user's bash configuration
source /user1/ngmm/tr855969/.bashrc

# Print a start message
echo "Starting my shell script"

# Define variables for modules and directories
MY_PYTORCH_MODULE="pytorch/1.11.0/cuda/11.3.1/gpu"
MYROOTDIR="/user1/ngmm/tr855969/Desktop/Taiabur/ngmm-nnunet/"

# Load the PyTorch module
module load ${MY_PYTORCH_MODULE}

# Change to the project root directory
cd $MYROOTDIR

# Activate the Conda environment
conda activate /user1/ngmm/tr855969/.conda/envs/env_tf

# Execute the nnUNet prediction command
nnUNetv2_predict -d 1 -i /user1/ngmm/tr855969/Desktop/Taiabur/ngmm-nnunet/dataset/nnUNet_test_data/raw -o /user1/ngmm/tr855969/Desktop/Taiabur/ngmm-nnunet/dataset/nnUNet_Prediction_Results/Dataset001_Wdr47Kusss/2d -f 0 1 2 3 4 -tr nnUNetTrainer -c 2d -p nnUNetPlans

# Get the current date and time
CURRENT_DATETIME=$(date "+%Y-%m-%d_%H-%M-%S")

# Log Python and Conda versions
python --version > "versions_${CURRENT_DATETIME}.txt" && conda --version >> "versions_${CURRENT_DATETIME}.txt"

# Print an end message
echo "Ending the shell script"
