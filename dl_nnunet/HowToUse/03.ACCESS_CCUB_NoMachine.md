# Configuration of NX NoMachine

This guide provides detailed steps to configure NX NoMachine for connecting to the machines at the Centre de Calcul de l'Université de Bourgogne.

## Prerequisites

- NX NoMachine client installed on your system (Linux, Windows, or Mac).
- User account on the CCUB machines.

## Steps

1. **Download and Install NX NoMachine Client**
   - Download the NoMachine client from [NoMachine's official website](https://www.nomachine.com/download).
   - Install the client on your system following the provided instructions.

2. **Manual Connection Setup**
   - Open the NoMachine client and click on "New connection".
   - Select "NX" as the protocol.
   - Enter `nx-ccub.u-bourgogne.fr` in the "Host" field and keep the port as `4000`.
   - Disable "Use UDP communication for multimedia data".
   - Choose "Password" for authentication.
   - Name the connection, e.g., `NX-CCUB`.
   - Click on "Connect" and enter your CCUB login credentials.
   - Select "New desktop or virtual session" and check "Save this setting in the connection file".
   - Click on "Create a new virtual desktop" to start the session.
