# Running 3D Slicer on CCUB Server

This document provides instructions on how to connect to the CCUB server using NoMachine and run 3D Slicer.

## Prerequisites

- NX NoMachine client installed on your local machine.
- User account on the CCUB server.

## Steps

### 1. Connect to CCUB Server using NoMachine

[Configuration of NX NoMachine](03.ACCESS_CCUB_NoMachine.md) 

### 2. Run 3D Slicer on CCUB Server

1. **Open Terminal**
   - After establishing the NoMachine session, open a terminal within the virtual desktop environment.

2. **Execute 3D Slicer using 3dsub**
   - In the terminal, run the following command to start 3D Slicer:
     ```sh
     3dsub -q 3d@webern01 /work/shared/ngmm/soft/Slicer-5.6.1-linux-amd64/Slicer
     ```
